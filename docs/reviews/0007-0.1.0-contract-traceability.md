## Conceptual proposals

0002's broad entity model, cardinalities, occurrence records and authentication
contracts remain proposed. The first-contract Agent identity question is resolved
only for 0.1.0 by the Key/actsAs/invoke rule. 0003's whole-model conformance,
profiles, compatibility negotiation and general evidence regime remain proposed;
0.1.0 names only seven operation features and its report contract. 0011's larger
first-contract discussion is superseded for this adopted scope by the concrete
D/G/R text, including bounded G resolution beyond 0011's original D boundary.
None of these conceptual proposals is adopted wholesale.
