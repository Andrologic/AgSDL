# Decision 0002: publish version 0.0.1 as a conceptual pre-draft

- Status: accepted
- Date: 2026-09-02

## Context

The repository has reviewed conceptual research and proposals, but no accepted
language syntax or normative specification.

## Decision

Version `0.0.1` will use the tag `v0.0.1`. It is a non-normative conceptual
pre-draft and makes no promise of syntax, compatibility, conformance, execution,
or interoperability.

The release includes proposals 0001 through 0004 as conceptual inputs. All four
retain the `proposed` status and remain non-normative.

## Consequences

Readers may use the release to review the project's direction and open
questions. They must not treat it as an implementable language version or as a
basis for compatibility, conformance, execution, or interoperability claims.
