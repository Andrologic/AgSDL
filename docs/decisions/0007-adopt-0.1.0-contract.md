## Maintainer authorization and selected scope

After the explicit question whether to adopt the current contract and retain
the same declared actor when changing engines, the maintainer delegated:
"Je te laisse piloter tout ça jusqu'à que la 0.1.0 soit prête".
The orchestrator records adoption of the recommended scope under that delegation.
This is not a claim that the maintainer individually approved every historical
choice or every earlier proposal. Publication requires separate authorization.

The selected written contract is proposal 0013 `proposal-0013-candidate-1` at
`280347eec4e2e051d296f9271bfccc86c98d4d40`, including its expressly inherited
proposal 0012 candidate-2 rules at
`009a51eb301688f06d29bb7e2f1784e3c4a4cc98`, with the replacements listed in
0013. The final local experimental evidence is integrated at the application
base above. The review dossier and local retained evidence record the review
and implementation consequences examined before this adoption.

Adopt D, G and R with the seven existing operations: inspect, validateD,
validateG, resolveG, validateR, exchange and lossyExchange. Preserve their distinct
phases, D prerequisites, exact diagnostics, unknowns, deferrals, exclusions,
inventory and byte boundaries. LossyExchange remains unconditional refusal.
Direct supplied annexes are the entire resolution boundary; semantic extensions
have no interpreter in this edition. No full-model or execution verdict follows.

Resolve the remaining Principal choice by retaining the selected contract:
Agent Key identifies the Definition; each Agent has one actsAs Principal;
invoke.principal equals it. Engine configuration does not rebind that Principal.
Concrete authentication and actual authority remain external. The configuration
pin, explicit Interface operations, sequential approvals, open per-Agent engines,
Tool implementations and reusable content retain precisely the selected rules.

seven operation feature Editions listed in the specification name only this

accounts for inherited, replaced and excluded sections and mechanical changes.

new semantic feature is authorized by this decision.
