# AgSDL 0.1.0 local release notes

- Status: ready in the local repository, unpublished.
- Contract marker: `agsdl-0.1.0`.
- Scope: bounded first draft for static D/G/R declarations and seven reader
  operations.

This is the first implementable AgSDL draft. It is intentionally small. It does
not claim a stable universal language, execution support or interoperability.
No tag, release, push or publication is authorized by these notes.

## Included

- normative Document, Graph and Runtime declaration chapters;
- closed JSON notation, official edition and feature identities, report grammar
  and exact preservation boundaries;
- derived JSON Schema Draft 2020-12 shapes;
- independent non-normative Python and JavaScript readers for `inspect`,
  `validateD`, `validateG`, `resolveG`, `validateR`, `exchange` and
  `lossyExchange`;
- a pinned 137-case official corpus, coverage index and neutral comparator;
- one official, non-normative general-purpose D/G/R example with two explicit
  configurations and illustrative custom engine identities; and
- contributor, roadmap, tooling and conformance guidance.

## Contract boundaries

The seven operations are separate contracts. A validation pass does not certify
the whole document, and an exchange result does not validate the exchanged
bytes. Historical candidate reports retain their historical markers.

Runtime declarations describe explicit configurations and claimed
compatibility. They do not execute a graph, verify evidence, authenticate a
Principal, authorize an Action, launch an engine or establish runtime readiness.
The edition provides no default engine, automatic Tool fallback, configuration
inheritance, transitive dependency resolver, semantic extension interpreter or
lossy conversion.

## Publication

Publication remains a separate maintainer decision. A later tag or announcement
must use the reviewed local state without broadening these claims.
