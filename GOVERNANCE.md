# Governance

AgSDL is in incubation. Its maintainers decide changes through reviewed pull
requests.

A change of meaning requires:

1. an issue describing the problem;
2. enough review time to examine its consequences for documents, harness
   modules and implementations;
3. an explicit maintainer decision, recorded in
   [decisions](docs/decisions/README.md) when the change is significant;
4. the matching updates to the specification, schema, validator, conformance
   cases and examples, in the same pull request.

Before a stable 1.0 release, the project will define a broader governance
model: maintainership, decision rules, versioning authority and appeals.
Licensing and contributions are settled in
[decision 0017](docs/decisions/0017-licensing-and-contributions.md).
