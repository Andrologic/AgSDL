# Governance

AgSDL is in a pre-draft incubation phase. Repository maintainers approve changes
through reviewed pull requests.

Normative decisions require:

1. a written proposal;
2. a review period long enough to examine compatibility and implementation
   consequences;
3. an explicit maintainer decision recorded in the proposal;
4. corresponding updates to the specification, schemas, and examples when they
   exist.

The project will define a broader governance model before publishing a stable
version. That model must cover maintainership, voting or consensus rules,
versioning authority, appeals, and the licensing of normative and executable
artifacts.
